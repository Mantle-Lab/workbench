# Mantle-Lab Workbench

A rig editor for [HeadRush Prime, Core and Flex Prime](https://www.headrushfx.com/). It works over Wi-Fi with your unit and adds the editing the built-in editor doesn't have: drag pedals and whole chains between rigs, combine a guitar path and a mic path into one rig, and edit footswitches, scenes and expression pedals, with a backup made before anything is saved.

**Website, instructions and help:** https://neilmantle.info/mantle_lab/workbench/

## Download

Get the latest **Setup.exe** from [Releases](https://github.com/Mantle-Lab/workbench/releases/latest).

## What you need

* A HeadRush Prime, Core or Flex Prime on firmware 5.x
* Windows 10 or 11, 64-bit (Mac and Linux versions are planned)
* Your computer and your HeadRush on the same Wi-Fi network

The installer isn't code-signed yet, so Windows may say "Windows protected your PC": click **More info**, then **Run anyway**.
